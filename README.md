# Company-Smart Mock Interview Coach 🎯

A Streamlit academic demo that lets candidates practice role-based interview questions and receive simple keyword-based feedback.

## Features
- Select a company style and job role
- Practice a short set of interview questions
- Enter answers and submit them
- See per-question demo scores and feedback
- Download a JSON feedback report

## Setup

```bash
python -m venv .venv
```

Activate the environment, then install dependencies:

```bash
pip install -r requirements.txt
```

Run the app:

```bash
streamlit run app.py
```

## Roles included
- Software Engineer
- AI/ML Engineer
- Data Analyst
- Python Developer

## Academic prototype note
Scoring is keyword matching and should not be interpreted as a professional interview evaluation. The institution's ten-year interview archive was not provided and is not included; it can be integrated when available.
